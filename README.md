# SpriteSheetPacker — 多边形精灵图打包工具

## 告别矩形浪费，用多边形打包让你的图集更小、渲染更快

在游戏开发中，将零散的小图合并为精灵图集（Sprite Sheet）是优化性能的基本操作。然而传统的矩形打包方式，会在不规则形状的精灵周围保留大量透明像素，白白浪费纹理空间和 GPU 显存。

**SpriteSheetPacker** 采用**多边形紧密贴合**技术，自动追踪每个精灵的 Alpha 轮廓，生成贴合实际形状的多边形区域（vertices + triangles），大幅减少图集中的透明像素浪费。输出标准的 PNG 图集 + TexturePacker 兼容 JSON 元数据，可直接用于 Cocos2d、Unity、Phaser 等主流游戏引擎。

---

## 核心功能

### 📐 Alpha 智能裁切
自动检测并去除每个精灵四周的透明像素，记录 trim 偏移量，最大限度减小实际占用面积，同时保证在引擎中的精确定位。

### 🔺 多边形轮廓生成
通过 Alpha 边界扫描 → 凸包生成 → 三角化处理，为每个精灵自动构建紧贴内容的多边形数据（vertices + triangles），这是传统矩形打包工具不具备的高级特性。

### 📦 FFDH 高效装箱
采用 First Fit Decreasing Height 装箱算法，按高度降序排列后逐行放置，确保图集空间利用率最大化。当一张图集放不下时，自动分页输出多张图集。

### 🔄 可选旋转优化
开启旋转后，系统会自动将"宽大于高"的精灵旋转 90°，使其更适合行排布局，进一步节省图集空间。

### 🖼️ POT 尺寸支持
可选强制输出 2 的幂次方尺寸（256/512/1024/2048），满足部分 GPU 和旧设备对纹理尺寸的要求。

### 📱 移动端模式
一键将最大宽高限制为 2048×2048，适配移动设备纹理上限，超出部分自动分页。

### 📂 递归扫描
支持递归扫描子目录中的所有图片文件，自动保留相对路径作为精灵名称，目录结构一目了然。

### 🖱️ 拖拽操作
支持将文件夹直接拖拽到窗口，自动填充输入路径，操作更高效。

## 常见问题

**Q：输出的 JSON 格式与 TexturePacker 兼容吗？**
A：完全兼容。输出的 JSON 包含 frames（frame/rotated/trimmed/spriteSourceSize/sourceSize/vertices/verticesUV/triangles）和 meta 信息，可直接用于 Cocos2d、Unity、Phaser 等引擎。

**Q：一张图集放不下怎么办？**
A：工具会自动分页，生成 spritesheet0.png、spritesheet1.png... 多张图集，每张都有对应的 JSON 文件。

**Q：免费版的水印会影响使用吗？**
A：免费版输出的图片会带有 TRIAL 水印标识，注册后即可去除。在开发测试阶段可先使用免费版验证效果。

**Q：和 PngPacker 选哪个？**
A：如果你的项目使用传统 Cocos2d 引擎且只需 Plist 格式，选 PngPacker；如果追求更高的空间利用率和渲染性能，或需要兼容多种引擎，选 SpriteSheetPacker。
